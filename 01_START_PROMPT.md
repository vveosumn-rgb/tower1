### Правила (обязательные)
- **Накопительность.** Раунд = новое + улучшение старого + графика + «умнее» ИИ + тесты + журнал рисков. Старые тесты и кадры остаются.
- **Честность.** Всегда различай «проверено / не проверено». Боты и JVM-замеры — прокси, не доказательство веселья и не FPS телефона. Графику не называй AAA. Не пиши, что что-то работает, если не запускал.
- **Детерминизм.** Сид забега → потоки случайности `Rng.stream(seed, 1…6)` в `World.reset`, 7 — встреча. Новые случайности — только новым потоком; в потоки 1–6 вызовов не добавлять.
- **Производительность.** В `update`/`draw` без аллокаций (пулы, кэш Paint/Bitmap); лимиты: `MAX_ENEMIES = 400`, частицы по пресету.
- **Данные.** Контент — таблицы в `content/`; новое оружие, враг, босс, существо, экран, звук, поле профиля — по рецептам `docs/CODE_MAP.md`. Новые спрайты — в `SpriteBank.warmUp()`; новые ключи сохранения — с диапазонами и тестом подделки; новый звук — поднять `SoundSynth.VERSION`.
- **Интерфейс.** Русский; проверять экраны 720×1280, 1080×2340, 1600×2560; тексты через `tx.fit`.
- **Проверка.** Логика в `World` без Android (быстрые JUnit) + визуальные Robolectric-тесты с PNG; **кадры смотреть глазами**; бот-трассировка для справедливости; независимая сверка документов с кодом перед сдачей.
- **Сдача этапа.** Чистый коммит → `scripts/verify.sh <ЭТАП>` (добавь ожидаемое число кадров для нового этапа в `scripts/verify.sh`) → записи в `PIPELINE/HANDOFF.md` (шаблон в `PIPELINE/RULES.md`), `PIPELINE/QA_<ЭТАП>.md`, `PIPELINE/BACKLOG.md` → `python3 scripts/gen_mechanics_coverage.py` → push в ветку.
- **Git и безопасность.** Без force-push и переписывания истории; не коммить ключи и `local.properties`; не запускай параллельных писателей в одном дереве.
- **Объём.** Не выходи за этап; идеи вне этапа — в `PIPELINE/BACKLOG.md`.

### Формат отчёта по этапу
1. Результат в 1–2 предложениях. 2. Что проверено (числа: тесты, кадры, `verify.sh`) и что **не** проверено. 3. Что решить владельцу. 4. Ссылки на артефакты (APK, документы, коммит).
