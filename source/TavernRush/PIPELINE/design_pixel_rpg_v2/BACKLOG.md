# Бэклог (P0 — блокер, P1 — важно, P2 — хорошо бы)

**Текущая очередность:** NEXT_10_ROUNDS.md — ещё 10 раундов N01–N10 после первого базового цикла. Старые метки R1–R10 ниже обозначают первоначальную разбивку/историю, не число оставшихся раундов.

## Известно на старте (baseline)
- [x] P0 [R1] Восстановлена машина состояний: меню → забег → карты → пауза → итоги → хаб; сценарии касаний проходят.
- [x] P0 [R1] Остановка отменяет поколение потока, повторный start не создаёт второго писателя; onPause ставит забег на паузу. Смоделирован зависший lockCanvas.
- [x] P0 [R1] Обычный спавн вынесен за область обзора камеры; кольцевое событие имеет предупреждение перед контактом.
- [x] P1 [R1] Seeded RNG и независимые потоки спавна, лута, карт, боя и эффектов.
- [x] P1 [R1] Подписанные сохранения, резервная копия, страховочная награда за прерванный забег, четыре улучшения хаба.
- [x] P1 [R1] Процедурные персонажи, арена, таверна, иконки и русский интерфейс; 19 кадров на четырёх размерах.
