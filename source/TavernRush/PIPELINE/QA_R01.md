# QA — контрольная точка R01

## Выполнено

- Полный предварительный verify: BUILD SUCCESSFUL, 46 тестов, 0 failures/errors/skipped.
- Шесть классов: FoundationTest (24), FrameClockTest (7), LifecycleTest (3), GameplayTest (9), QuickSimTest (1), ScreenshotTest (2).
- Восемь обычных бот-забегов: четыре стратегии × два сида. Проверяется отсутствие NaN/Infinity, корректные границы волны, времени и золота; сырой вывод хранится в SIMULATION_R01.txt.
- Отдельный тест полного десятиволнового пути до победы, записи награды, повторного чтения профиля и выхода в хаб. Для гарантированного достижения конца в этом тесте отключён урон герою; это проверка состояний, не доказательство баланса.
- Реальный урон каждой из шести атак проверен отдельно; максимальные уровни имеют конечные положительные параметры.
- Проверены переполнение пулов, пауза, неверные числовые входы, идемпотентность награды, HMAC/диапазоны/дубликаты сохранения, бэкап, временный файл и сбой восстановления.
- Часы тестируются на 30/60/90/120/144/240 Гц и частых программных кадрах: симуляция не обгоняет принятые часы.
- Смоделирован lockCanvas, не реагирующий на interrupt: stop → resize → start не создаёт двух писателей и не возобновляет приостановленный забег.

## Визуальная проверка

19 отдельных PNG, а не только контактная сетка. Размеры: 1080×2340 с отступами 96/48, 720×1280, 1440×3200, 1600×2560. Рендер — Robolectric, Android 34, native graphics.

| Кадры | Проверено |
| --- | --- |
| 01–02 | Заставка, крупный заголовок, контраст и доступные кнопки меню |
| 03–06 | Онбординг, баннеры волн, герой, оружие, карточки, читаемый HUD в толпе |
| 07 | Пауза, четыре действия, подпись «убито», счётчик не обрезан |
| 08–09 | Смерть и итоги, «Противник», показатели и разбивка награды, две кнопки |
| 10–12 | Таверна, цены, списание золота, уровень покупки, возвращение в меню |
| 13–15 | Карты и арена на малом экране, QHD и планшете; длинные названия помещаются |
| 15c | Ручное завершение: золотой «Забег окончен», а не ложная смерть; панель помещается |

После изменений только 07/09/15c изменили SHA-256; они повторно просмотрены по одному. Остальные 16 кадров совпали с уже проверенными пиксель-в-пиксель.

## Не подтверждено / остаётся сделать

- Установка, звук, вибрация, реальные системные панели, драйверы SurfaceView и производительность на телефоне.
- Целевые 60 FPS при 200+ врагах: тесты пулов этого не доказывают.
- Интересность для людей, отсутствие доминирующего билда и долгосрочная экономика: восемь ботов недостаточны.
- Биомы, боссы, герои, большой арсенал и остальные цели раундов 2–10.
- Защита от root, модифицированного APK и отката подписанного старого сохранения. HMAC пока с совместимым ключом клиента; авторитетного сервера нет.
- Перенос прогресса из старого приложения в preview и релизная подпись.

Финальный verify после контрольного коммита: `scripts/verify.sh R01-1-final`. Его статус и SHA коммита находятся во внешнем `pipeline/last_verify.txt`; до его выполнения эта запись не заменяет фактический результат.
