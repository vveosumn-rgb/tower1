# Ускоренные экспедиции R08

Матрица фиксированных сидов: 6 областей × 3 намерения × обычный и неуязвимый бот = 36 походов. DT=1/60; до 180 игровых секунд. Без телепортаций, выдачи наград и принудительного убийства врагов в этих прогонах. Бот автоматически выбирает карты и применяет доступные приёмы. Защищённый режим отделён в колонке invulnerable и предназначен для диагностики доступности маршрута.

baseline.csv — исходный R07 с добавленным измерителем. after.csv — R08 с улучшением навигации/прицеливания бота и исправлениями самой игры. Поля bossHp/damage/px/py добавлены только в after для диагностики. summary.json — механическая агрегация.

До: 11 выходов из 36, 8 из 18 в защищённой половине; поиск следа 0 из 12. После: 33 выходов из 36, 18 из 18 в защищённой половине; поиск следа 12 из 12. В обычной половине три смерти, все состояния конечные. Ни один защищённый маршрут не остался застрявшим. Конкретные исходы зависят от сидов, поведения бота и его выбора карт; это не вероятность победы человека.

Менялись несколько факторов одновременно, в том числе бот. Поэтому нельзя всю разницу приписать балансу или назвать доказательством улучшения удовольствия. Это не 36 раундов разработки. После исправлений проверка требует завершения всех защищённых сценариев и всех сценариев следа, а не только конечности координат.

Точные времена тестов доступны в Gradle XML / итоговом журнале verify. Длительность CSV — шаги симуляции, не FPS, не человеческий сеанс. Автоматические кадры UI используют подготовленные состояния и не подменяют эти походы.
