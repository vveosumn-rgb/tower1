# R07 — изменение покрытия, не завершение всех 39 игр

Базовый построчный аудит 39 референсов сохранён в COVERAGE_R06.md; исследования отзывов — в пакете design_v3. Новое чтение внешних отзывов в R07 не проводилось. Ни один референс целиком не объявляется реализованным.

| Мотив из сохранённого исследования | Реализованное приближение R07 | Остаётся |
|---|---|---|
| Monster Sanctuary: вид меняет решение | Мохокрыл: статическая защита и поиск, две специализации, отдельная модель | Больше содержательных сочетаний и их человеческая проверка |
| Roots of Pacha / Potion Permit: помощь и знакомство | Восстановление воды, безопасное наблюдение, подход существа без убийства | Разнообразные встречи остальных видов |
| Stardew / Dave: дом продолжает поход | Сад растёт от новых открытий; нектар и настой реально помогают экспедиции | Поздняя повторяемость сада без конечного запаса открытий |
| Children of Morta / Kynseed: память и привязанность | Журнал реального спутника, три короткие главы мастера, сцены характера | Нелинейные истории, самостоятельные жители |
| HAAK / Core Keeper: желание исследовать | Намерение поиска и скрытый тайник; близкий осмотр даёт альтернативу редкому виду | Уникальные маршруты и большие биомы |
| Kingdom / защита команды | Полог уменьшает урон мастеру только в своей зоне | Новые самостоятельные оборонные задачи |

Никаких новых доказанных предпочтений или гарантий потока из этой реализации не следует. Остальные пункты исходных архивов, гибриды, fusion, эволюционные силуэты, транспорт, профессии и полнота всех механик остаются открытыми. R07 — один очередной связный этап, не десять дополнительных полных циклов.
