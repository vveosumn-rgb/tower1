## 📊 ЧАСТЬ 1: ПОЧЕМУ ФЬЮЖН ЗАЛИПАЕТ

### **Гибрид DNA: Survivor.io + Lucky Tavern**

#### **Survivor.io (экшн-ядро)**
- **Что:** Орды врагов, волны 3–5 мин, один палец, выживание
- **Психология:** Адреналин, near-miss спайк (герой на 10–30% HP), динамика
- **Проблема жанра:** Однообразие, выгорание после 5–7 дней (давит монотонностью)

#### **Lucky Tavern / Balatro (переменная награда)**
- **Что:** После волны — веер из 3 карт (левая скучная, правая riskyDream)
- **Психология:** Казино-ревизит (near-miss синергии), джекпот 5% (звон, ×3–5 урон, вирусный момент)
- **Решение:** Таверна разбивает монотонность, развилки = переменная награда (дофамин-спайк)

#### **Тавернный сеттинг (уют)**
- **Что:** Фэнтезийная таверна вместо пустыни/города (зомби выгорел)
- **Психология:** Cozy-гейм контекст = расслабленный вайб + экшн сверху
- **Эффект:** Можно играть перед сном (низкий страх), но адреналин внутри волн

---

### **Дофаминовая петля: 4 кита**

```
┌─────────────────────────────────────────────────┐
│ 1️⃣ ПРОСТОТА (одна кнопка, движение = выживание) │
│    ↓ Включение за <5 сек                         │
│ 2️⃣ NEAR-MISS SPIKE (волна 4, HP 10–30%)          │
│    ↓ Учащённое сердцебиение, выхода за край    │
│ 3️⃣ СИНЕРГИИ (меч+посох=ярость, молния+лук)     │
│    ↓ Ощущение силы, build-crafting              │
│ 4️⃣ ДЖЕКПОТ (5% → ×3–5 урон, звон, вирусный)    │
│    ↓ Переменная награда, скриншот/видео         │
└─────────────────────────────────────────────────┘
```

**Цикл:** Волна → Near-miss → Выживаешь → Таверна (выбор) → 50% базовый апгрейд → 5% джекпот (VIRAL!) → Вволна сложнее → Повтор

**Удержание:** Каждые 2–3 сессии джекпот → Сильное ощущение прогресса → "Сыграю ещё раз"

## 🎯 ЧАСТЬ 2: ЦЕЛЕВЫЕ МЕТРИКИ И КПЭ

### **Жанровые бенчмарки**

| Метрика | Survivor.io | Lucky Tavern | **Tavern Rush (Таргет)** |
|---------|-------------|--------------|------------------------|
| **D1** | 45–55% | 60–70% | **65%** (адреналин+выбор) |
| **D7** | 25–35% | 35–45% | **40%** (синергии, таверна) |
| **D30** | 10–15% | 15–25% | **18%** (роадмап: новые этапы) |
| **Средняя сессия** | 4–5 мин | 3–4 мин | **3.5 мин** (идеально для мобила) |

| **Retention DAU** | Волны игрок идёт в волну 10+ | Развилки держат, но нужен хаб | **Волны+апгрейды** (каждый день новая ветка) |

### **Ловушки жанра — как мы избежали**

| Проблема | Vampire Survivors | Lucky Tavern | **Наше решение** |
|----------|-------------------|--------------|-----------------|
| Монотонность | На волне 10+ однообразие | OK, но без экшна | **Волны как казино** (каждая уникальна) |
| AFK-грейндинг | Есть (юзеры афкят) | Нет (нужен выбор) | **Обязательный контроль** (герой умрёт) |
| Усталость | После 5 дней жжёт | После неудачи можно уйти | **Сессии 3.5 мин**, перерыв естественный |
| Непредсказуемость | Скучно (всегда спаун) | Раз-раз-раз! Стресс | **50% спокойный, 5% джекпот, 45% риск** |
